# Бабло-Сити: заезд на Луну — как запустить в Telegram

Вся игра — один файл `index.html`. Сервер, база данных и программирование не нужны.
**Токен бота в коде НЕ нужен** и никуда его вставлять не надо. Никому его не присылай.

Проверить на компьютере: дважды кликни `index.html`, он откроется в браузере. Управление — стрелки ← →.

---

## Шаг 1. Бесплатный хостинг на GitHub Pages (≈5 минут)

1. Открой https://github.com → **Sign up** (если аккаунта нет) → зарегистрируйся и подтверди почту.
2. Справа вверху нажми **+** → **New repository**.
3. В поле **Repository name** впиши `bablo-city` (латиницей, без пробелов).
4. Выбери **Public** (для бесплатных Pages нужно именно это). Нажми **Create repository**.
5. На открывшейся странице нажми ссылку **uploading an existing file**
   (или **Add file** → **Upload files**).
6. Перетащи в окно файл `index.html` → внизу нажми зелёную кнопку **Commit changes**.
7. Вверху репозитория открой вкладку **Settings** → в левом меню **Pages**.
8. В блоке **Build and deployment**: **Source** = `Deploy from a branch`,
   **Branch** = `main`, папка `/ (root)` → **Save**.
9. Подожди 1–2 минуты и обнови страницу. Вверху появится
   **Your site is live at** `https://ТВОЙ-ЛОГИН.github.io/bablo-city/`.
   Это и есть ссылка на игру. Открой её в браузере телефона и проверь, что игра запускается.

## Шаг 2. Бот в @BotFather

1. В Telegram открой **@BotFather** → нажми **Start**.
2. Отправь `/newbot`.
3. Введи имя бота (видно людям), например `Бабло-Сити`.
4. Введи username (латиницей, в конце обязательно `bot`), например `bablo_city_bot`.
5. BotFather пришлёт токен. **Он не нужен для игры**: сохрани его в заметках и никому не показывай.

## Шаг 3. Кнопка запуска игры в боте

1. В @BotFather отправь `/mybots` → выбери своего бота.
2. **Bot Settings** → **Menu Button** → **Configure Menu Button** (или **Edit Menu Button URL**).
3. Отправь ссылку из шага 1: `https://ТВОЙ-ЛОГИН.github.io/bablo-city/`.
4. Отправь название кнопки, например `🏎️ Играть`.
5. Открой своего бота → внизу слева появится кнопка **🏎️ Играть** → игра откроется внутри Telegram.

## Шаг 4 (по желанию). Прямая ссылка на игру

Нужна, чтобы кидать друзьям ссылку вида `t.me/bablo_city_bot/game`, которая сразу открывает игру.

1. В @BotFather отправь `/newapp` → выбери бота.
2. Введи название (`Бабло-Сити`) и короткое описание.
3. Попросит картинку 640×360 — отправь любую подходящую картинку.
4. Попросит GIF — отправь `/empty`.
5. Отправь ссылку из шага 1.
6. Введи короткое имя, например `game`.
7. Получишь ссылку `https://t.me/bablo_city_bot/game`.

Чтобы кнопка «Поделиться» в игре вела на эту ссылку, а не на github.io: открой `index.html` в GitHub
(клик по файлу → значок карандаша ✏️), найди строку `const SHARE_URL='';`
и впиши ссылку между кавычками: `const SHARE_URL='https://t.me/bablo_city_bot/game';` → **Commit changes**.

## Как обновлять игру

1. Открой репозиторий `bablo-city` на GitHub.
2. **Add file** → **Upload files** → перетащи новый `index.html` (старый заменится) → **Commit changes**.
3. Через 1–2 минуты игра обновится. В Telegram закрой и заново открой игру. Если видна старая версия, подожди ещё пару минут: Telegram кэширует страницу.

## Что внутри

- Рекорд хранится в облаке Telegram (CloudStorage), вне Telegram — в браузере.
- Вибрация при ударе и бонусах работает только в мобильном Telegram.
- Кнопка 🔊 слева сверху выключает звук.
